Read CLAUDE.md. Add a contractor to the register with the public liability limit you require of them.

Run `npm run cover -- add-contractor --name= [--trade=] [--entity=] [--required=] [--email=] [--code=] --actor=`. Flags use `--name=value`; quote values with spaces. Add `--json` for structured results. Use the operator's actual values, drop optional brackets, and never run a literal placeholder.

Put the real person doing this in `--actor`. Money is in dollars. Then offer /cert-request.
