Read CLAUDE.md. Draft the notification of a loss to the broker or insurer from the claims register.

Run `npm run cover -- claim-notification <claim>`. Flags use `--name=value`; quote values with spaces. Add `--json` for structured results. Use the operator's actual values, drop optional brackets, and never run a literal placeholder.

Writes a draft to drafts/. Present the path and the date the insurer must hear by. Nothing is sent.
